Codex Account Hub - 轻量试用版
版本：0.2.9
平台：Windows 10/11

本版基于 0.2.8 修改，保留原有图形界面、账号导入、当前账号导入、账号重命名、删除记录、切换与旧账号迁移功能。

0.2.9 修复：
- 修复 Windows PowerShell 5.1 下迁移或保存账号时因 `File.Replace` 空备份路径导致的“路径的形式不合法”异常。
- 修复切换账号替换当前认证文件时的同类异常；仍使用临时文件校验并在替换后清理临时备份。

0.2.8 调整：
- 将“联系作者”改为“复制邮箱”，点击按钮或邮箱文字只复制到剪贴板，不再打开邮件客户端或跳转页面。
- 作者邮箱仍清晰显示为：wozhixiangxinni@foxmail.com。

0.2.6 修复与调整：
- 修复迁移路径每次都弹出文件夹选择的问题：首次选择后保存到当前 Windows 用户的 %LOCALAPPDATA%\CodexAccountHub\settings.json；再次迁移时可直接使用已记住路径，也可选择更改路径。
- 兼容读取 0.2.4 原有 migration-source.txt 路径设置，并迁移到新的设置位置。
- 默认路径改为 Windows 当前用户的“文档\CodexAccounts”，不写死具体用户名。
- 刷新账号列表时重新检查本地账号文件，尝试补全旧记录中缺失的邮箱。
- 扩展邮箱识别字段与 JWT 声明解析；若文件中有多个不同邮箱，不会猜测其中一个。
- 将“未能读取邮箱”细分为“文件有效，未发现可识别邮箱”或“账号文件不可读/不存在”，避免把邮箱未识别误判为 JSON 无效。
- 最多管理 5 个账号；达到上限时阻止新增并提示。
- 账号索引采用临时文件写入和替换，更新前自动备份索引文件。

重要边界：
- 旧版迁移只识别严格命名的 account1.json 和 account2.json；Windows 文件名大小写不敏感。文件必须放在用户选择的同一文件夹内。
- 邮箱识别依赖 auth.json 内实际包含可解析的邮箱声明；若文件未提供邮箱，程序会明确显示未识别，不代表凭据无效。
- 切换前必须完全退出 Codex、VS Code 及相关 Codex 会话。
- 本软件只在本机处理认证文件，不上传凭据，不修改 CC Switch++ 配置。
- 这是便携脚本应用，未进行代码签名；发布前仍应在干净的 Windows 10/11 环境测试。
