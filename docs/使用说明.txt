Codex 多账号管理器（Windows 10/11）
版本：0.2.9
轻量便携版；不需要安装，不需要管理员权限。

一、启动
1. 解压整个文件夹。
2. 双击“启动多账号管理器.vbs”。
3. 正常情况下只显示白色管理窗口，不显示 PowerShell 黑色窗口。
4. 如果 VBS 被系统策略禁用，可使用“启动多账号管理器（控制台备用）.bat”。

二、添加账号
A. 导入 Codex 登录助手导出的 auth.json：
1. 在浏览器中打开你已安装且信任的 Codex 登录助手扩展。
2. 确认扩展中是你自己的 ChatGPT 账号。
3. 点击扩展的“导出身份信息”或相应导出功能，保存 auth.json。
4. 在本软件点击“导入 auth.json”，填写账号名称并选择文件。
5. 软件检查 JSON 是否可读取，并尝试识别邮箱。若文件内没有可读取的邮箱声明，会显示未发现可识别邮箱；这不等于 JSON 无效。

B. 导入当前正在使用的 Codex 账号：
点击“导入当前账号”，软件从当前用户的 Codex 默认认证位置读取 auth.json，并复制到本地账号库。

C. 迁移旧版双账号（支持路径记忆）：
1. 点击“迁移旧账号/设置路径”。
2. 首次使用时，若默认目录中没有旧账号文件，会弹出文件夹选择窗口。
3. 选择旧版双账号工具中 account1.json、account2.json 所在的文件夹。必须选择“直接包含这两个文件”的那一层文件夹。
4. 软件会记住路径。下次点击迁移时，会询问是否直接使用已记住路径；选择“是”直接迁移，选择“否”重新选择/更改路径，选择“取消”退出。
5. 软件只识别两个固定文件名：account1.json 和 account2.json。文件名必须完全对应（Windows 文件系统通常不区分大小写），不能随意改成 account3.json、工作号.json 等名称。
6. 迁移成功后，账号副本保存到本软件自己的账号库；原始文件不会移动或删除。
7. 默认路径为当前 Windows 用户的“文档\CodexAccounts”，不同电脑会自动使用各自的文档目录。

三、账号数量与命名
- 最多保存 5 个账号。
- 导入时可自定义名称，例如：工作号、个人号、备用号。
- 旧版迁移只导入 account1.json、account2.json；如需更多账号，请用“导入 auth.json”分别添加。

四、切换账号
1. 完全退出 Codex、VS Code 和正在运行的 Codex 会话。
2. 选中目标账号，点击“切换到选中账号”。
3. 确认提示后，软件会先备份当前 auth.json，再用临时文件验证并替换目标认证文件。
4. 重新打开 Codex，检查实际登录邮箱。

五、文件保存位置
软件按当前 Windows 用户动态使用以下位置：
  %USERPROFILE%\Documents\CodexAccounts\
    Accounts\              账号凭据副本
    Backups\               切换前备份及索引备份
    accounts-index.json     账号名称、邮箱及本地文件索引
  %USERPROFILE%\.codex\auth.json
    当前 Codex 认证文件
  %LOCALAPPDATA%\CodexAccountHub\settings.json
    迁移来源路径设置（自动记忆）

六、教学入口
软件内“导出教程”会显示简短步骤，并打开 Bilibili 搜索结果页。搜索结果由第三方平台提供，不代表软件作者背书某个视频或浏览器扩展。

七、复制作者邮箱
- 主界面显示作者邮箱：wozhixiangxinni@foxmail.com。
- 点击“复制邮箱”按钮，或点击底部邮箱文字，即可复制邮箱到剪贴板。
- 此操作不会打开邮件客户端，也不会跳转到其他页面。

八、重要安全说明
- auth.json 含有敏感登录凭据，安全级别应按密码处理。不要发给任何人，不要上传网盘或公开仓库。
- 本软件只在本机处理文件；没有账号上传、云同步、遥测或自动更新功能。
- 不会修改 CC Switch++、Codex config.toml 或 API 供应商配置。
- 切换前必须退出 Codex、VS Code 和相关会话，避免应用仍在写入认证文件。
- 删除记录不会自动删除账号凭据文件，以降低误删风险。
- 导入成功只代表 JSON 可读取，不保证令牌仍有效或服务端仍接受。
- 本软件不绕过登录验证；只管理用户自己合法取得的本地认证文件。
- 当前版本为便携脚本应用，尚未进行代码签名，也不是 Microsoft Store 安装包。Windows SmartScreen 或安全软件可能显示提示；请只从你信任的发布来源获取，并自行检查文件。

九、兼容性边界
- 适用于 Windows 10/11，需系统自带 Windows PowerShell 5.1、.NET Framework Windows Forms。
- 默认读取当前 Windows 用户的 %USERPROFILE%\.codex\auth.json。
- 邮箱识别依赖认证文件中可读取的身份声明；不同 Codex/登录助手版本格式可能不同。
- 请勿在多台设备之间共享同一份 auth.json。
