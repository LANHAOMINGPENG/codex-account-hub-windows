隐私与安全说明

Codex 多账号管理器是一个本地运行的 Windows 便携工具。

数据处理：
- 账号认证文件由用户主动选择，或从当前 Windows 用户的 Codex 默认认证位置复制。
- 账号凭据副本、备份和账号索引保存在本机 %USERPROFILE%\Documents\CodexAccounts。
- 账号索引只保存显示名称、可识别邮箱和本地文件路径，不主动保存 Token 字段。
- 本程序不提供云同步、账号注册、遥测、广告或自动更新，也不会主动上传认证文件。
- 导出教程入口会由用户主动打开第三方 Bilibili 搜索页面；第三方网站适用其自身隐私政策。

用户责任：
- auth.json 属于敏感登录凭据，应像密码一样保护。
- 不要分享、公开上传或通过不可信渠道传输 auth.json。
- 请在切换账号前关闭 Codex、VS Code 和相关会话。
- 用户可自行删除本地账号库和备份；删除前请确认不再需要这些凭据。

透明度：
本版本由 PowerShell 5.1 和 Windows Forms 构成，源代码随程序一并提供。用户可以检查脚本内容。
